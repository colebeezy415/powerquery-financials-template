# Power Query Financials Template

**What this is**  
A sample Excel workbook that demonstrates how to generate monthly Balance Sheet and Profit & Loss statements using **Power Query**. This repository contains a demo file with synthetic data for learning and testing purposes.

**Files**
- `Financials Template.xlsx` — Example workbook (sample data; safe to open).

**How to use**
1. Download the `.xlsx` file from the repository.
2. Open in Excel (Office 365 recommended).
3. Go to **Data → Get Data → Queries & Connections** to view Power Query queries.
4. Adjust the `Mapping` and `Adjustments` sheets to experiment with rollups and reclasses.
5. Can add monthly Trail balances for specified periods 
6. Refresh queries to generate updated monthly BS / P&L.

**Privacy & Disclaimer**
